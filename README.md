# 小红书自动评论插件

一个基于 Chrome Manifest V3 的浏览器扩展，用于在**网页版小红书**上按关键词搜索笔记并自动发布评论。

> ⚠️ 本项目仅供学习与技术研究使用。请遵守小红书平台规则，风险自负。

---

## 一、功能简介

| 功能 | 说明 |
| --- | --- |
| 关键词搜索 | 输入关键词，自动进入小红书搜索结果页 |
| 自动评论 | 打开笔记详情，按预设文案自动发送评论 |
| 数量控制 | 设置本次最多评论多少篇笔记 |
| 间隔控制 | 每条评论之间的等待秒数，避免操作过快触发风控 |
| 一键启停 | 点击插件图标，随时开始 / 停止任务 |
| 状态显示 | 实时显示当前进度与日志 |

---

## 二、安装步骤

1. 打开 Chrome 浏览器，在地址栏输入并进入：
   ```
   chrome://extensions
   ```
2. 打开右上角的 **「开发者模式」**（Developer mode）开关。
3. 点击左上角 **「加载已解压的扩展程序」**（Load unpacked）。
4. 在弹出的文件选择框中，**选择本插件所在文件夹**：
   ```
   D:\小红书插件
   ```
5. 加载成功后，浏览器右上角扩展栏会出现本插件图标。建议点击「固定」图标，方便随时使用。

---

## 三、使用步骤

1. **登录小红书网页版**：打开 `https://www.xiaohongshu.com` 并完成登录。
2. **点击插件图标**：点击浏览器右上角的本插件图标，打开弹窗面板。
3. **填写参数**：
   - **关键词**：要搜索的笔记关键词
   - **评论内容**：要发送的评论文字
   - **评论数量**：本次最多评论的笔记篇数（建议先填 1~2 篇试跑）
   - **时间间隔**：每条评论之间的等待秒数（**建议 ≥ 5 秒**）
4. **点击「开始」**：插件自动执行搜索与评论任务。
5. **点击「停止」**：随时中断任务，任务状态会保存到本地。

## 四、风险提示（务必阅读）

> 🚨 **使用自动化脚本操作社交平台存在账号被封禁 / 限流的真实风险，请谨慎使用。**

- **封号风险**：小红书对自动化、批量评论行为有风控机制，可能导致评论被删、限流甚至封号。
- **间隔建议**：单条评论间隔 **建议不低于 5 秒**，越接近真人操作越安全。
- **每日上限**：建议每天评论数量控制在较少范围内（如 **≤ 20 条**），避免高频操作。
- **遵守平台规则**：请遵守小红书《用户协议》与社区规范，不要发布垃圾、违规或营销内容。
- **先小规模测试**：**请先用 1~2 篇笔记试跑**，确认评论内容、间隔与账号状态正常后，再考虑扩大数量。
- 使用本插件产生的任何后果由使用者自行承担。

## 五、常见问题排查（Troubleshooting）

### 1. 提示登录已过期 / 无法评论
- 重新在浏览器中打开 `https://www.xiaohongshu.com`，手动登录账号。
- 确认登录状态后再重新运行插件任务。

### 2. 页面结构变化导致「选择器失效」（找不到按钮 / 输入框）
小红书前端会不定期改版，导致选择器失效。可按如下步骤修复：
1. 在小红书页面上按 **F12** 打开开发者工具。
2. 使用左上角的「元素选择器」点击评论输入框 / 发送按钮。
3. 在 Elements 面板中查看该元素的 `class`、`id`、`placeholder` 等属性。
4. 打开本插件的 `content.js`（或在 `chrome://extensions` 中点击本插件的「工作进程」调试），按实际属性替换对应的选择器字符串。
5. 保存后，在 `chrome://extensions` 页面点击本插件的 **刷新 🔄** 按钮重新加载，再重试。

### 3. 评论未发送成功（出现验证码 / 滑块）
- 平台可能弹出验证码或滑块验证，**自动化无法绕过**。
- 请切换到小红书页面**手动完成验证**，账号恢复正常后再继续使用。
- 建议调大评论间隔、减少数量，降低触发验证的概率。

### 4. 插件无反应 / 任务中断
- 在 `chrome://extensions` 找到本插件，点击 **刷新 🔄** 重新加载。
- 刷新小红书页面后再重试。
- 确认任务没有因为页面刷新而中断（本插件会在任务运行时自动重新注入脚本）。

## 六、文件说明

| 文件 | 作用 |
| --- | --- |
| `manifest.json` | 扩展清单，声明权限与入口 |
| `background.js` | 后台服务脚本：初始化存储、保活、消息转发、按需注入 |
| `content.js` | 内容脚本：在页面上执行搜索与评论操作 |
| `popup.html` / `popup.js` | 插件弹窗界面与交互逻辑 |
